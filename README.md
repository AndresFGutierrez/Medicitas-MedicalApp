# 🏥 App de Gestión Médica - C# Windows Forms

Aplicación de escritorio creada en **C# con Windows Forms** para la gestión eficiente de **médicos**, **pacientes**, **citas** y **historial médico**, incorporando lógica de negocio desde la base de datos con **procedimientos almacenados** y **triggers**. Incluye un sistema completo de autenticación y una interfaz amigable para el usuario.

---

## 🧩 Funcionalidades principales

- ✅ **CRUD completo** para:
  - Médicos
  - Pacientes
  - Citas médicas
  - Historial médico
- 🔐 **Inicio de sesión** con validación y **reconocimiento de sesión activa**
- 🗓️ Gestión de **agendamiento de citas**
- 🧠 Visualización del **historial clínico por paciente**
- 🧑‍⚕️ Asignación de pacientes a médicos
- 📜 Uso de **procedimientos almacenados** para todas las operaciones críticas
- ⚙️ Automatización mediante **triggers** en SQL Server
- 🎨 Interfaz UX/UI intuitiva y moderna en Windows Forms

---

## 🛠️ Tecnologías utilizadas

- Lenguaje: **C#**
- Plataforma: **.NET Framework**
- Interfaz: **Windows Forms**
- Base de datos: **SQL Server**
- Funcionalidades backend: 
  - Procedimientos almacenados
  - Triggers
  - Validaciones desde la base de datos

---

## 🔐 Sistema de autenticación

- Módulo de inicio de sesión con validación de credenciales
- Reconocimiento de sesión activa
- Restricción de acceso a funcionalidades según el usuario autenticado
